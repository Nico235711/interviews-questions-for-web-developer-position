Preguntas de CSS

¿Qué diferencia hay entre un id y una clase en CSS?

El id tiene mayor especificidad (importancia) que la class, lo que significa que si hay conflictos en las reglas CSS, el estilo aplicado al id prevalecerá sobre el de la class.

¿Cómo seleccionar un id y una clase dentro de CSS?

El id se selecciona con el # (hashtag) seguido del nombre del id, mientras que la class se selecciona con el . (punto) seguido del nombre de la class.

¿Con qué propiedades CSS puedo cambiar el color y el estilo de la fuente?

Con color cambias el color del texto y font-style puedes cambiar el estilo de la fuente (por ejemplo, cursiva o normal).

¿Cómo puedo cambiar el fondo de una web?

Con la propiedad background-color para cambiar el color de fondo, o background-image para agregar una imagen de fondo.

¿Cómo puedo dejar fijo un menú en una página web usando CSS?

Puedes usar la propiedad position: fixed; en el menú para que permanezca en una posición fija mientras se desplaza la página. Además, puedes usar top, bottom, left, o right para especificar la ubicación exacta del menú en la pantalla. Ejemplo: position: fixed; top: 0; left: 0; para fijar el menú en la parte superior izquierda de la página.

¿Cuáles son las distintas formas de posicionar elementos en CSS?

Las formas de posicionar elementos en CSS incluyen static, relative, absolute, fixed y sticky.

¿Con qué propiedad CSS puedo poner sombras tanto a textos como a cajas?

Con la propiedad box-shadow para cajas y text-shadow para textos.

¿Cómo puedo poner un borde redondeado a una caja en CSS?

Con la propiedad border-radius, puedes especificar el radio de los bordes redondeados.

¿Cómo puedo adaptar una página web para que sea responsive usando CSS?

Puedes usar consultas de medios (media queries) con la regla @media para aplicar diferentes estilos según el tamaño de la pantalla. También puedes usar unidades relativas como em, rem, y % en lugar de unidades fijas como px.

¿Cómo hacer que el contenido que sobresale de una caja no se vea en CSS?

Con la propiedad overflow puedes ocultar el contenido que sobresale de una caja. Los valores comunes son hidden, scroll y auto.

¿Qué diferencia hay entre flexbox y CSS Grid Layout?

flexbox se usa para diseñar elementos en una sola dimensión (fila o columna), mientras que CSS Grid Layout se usa para diseñar elementos en dos dimensiones (filas y columnas).

¿Cuál es la diferencia entre un preprocesador de CSS y un framework para CSS?

Un preprocesador de CSS como Sass o LESS extiende las capacidades de CSS con variables, funciones y otras características avanzadas, mientras que un framework de CSS como Bootstrap o Foundation proporciona un conjunto de estilos y componentes prediseñados listos para usar.

¿Qué propiedades usarías para hacer efectos y animaciones en CSS?

Para efectos y animaciones, usarías transition para transiciones suaves entre estados, y animation junto con @keyframes para animaciones complejas.

¿Cómo harías un efecto 3D en un elemento usando CSS?

Para un efecto 3D, puedes usar propiedades como transform: perspective() para establecer una perspectiva y transform: rotateX(), rotateY(), y rotateZ() para rotaciones en 3D.

¿Cómo manejar las capas y darles prioridad usando CSS?

Para manejar las capas y darles prioridad, usa la propiedad z-index en combinación con position (debe ser relative, absolute, o fixed) para controlar el apilamiento de elementos.
