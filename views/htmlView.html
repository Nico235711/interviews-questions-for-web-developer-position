Preguntas de HTML

¿Para qué sirve la etiqueta <head> en HTML?

Sirve para poner todo lo que necesita el navegador como los metadatos, el título de página, las hojas de estilos y los scripts de JS.

¿En qué se diferencia la etiqueta <head> de la etiqueta <body> en HTML?

En la etiqueta <head> se coloca todo lo que necesita el navegador y en el <body> va el contenido de la página.

¿Cómo poner una imagen en un documento HTML?

Con la etiqueta <img> utilizando el atributo src para la ruta de la imagen.

¿Cómo poner un video en una página web usando HTML?

Con la etiqueta <video> utilizando el atributo src para la ruta del video y atributos como controls para mostrar los controles del video.

¿Para qué sirve un <iframe> en HTML?

Un <iframe> permite incrustar documentos externos, como una página web, videos o mapas, dentro de otra página web.

¿Cómo crear un formulario en HTML?

Un formulario básico se crea con <form>, <div>, <label>, <input>, <button>, y otros elementos según sea necesario.

¿Qué hace un botón de tipo <submit> en HTML?

Manda la información del formulario a la ruta especificada en el atributo <action> del formulario.

¿Cuál es la diferencia entre la etiqueta <br> y la etiqueta <hr> en HTML?

La etiqueta <br> fuerza un salto de línea, mientras que <hr> crea una línea horizontal que suele utilizarse como separación.

¿Cuál es la etiqueta genérica para crear una caja en HTML?

La etiqueta <div> se utiliza para crear una caja genérica o contenedor.

¿Cuáles son las etiquetas semánticas de HTML5?

<header>, <nav>, <article>, <section>, <aside>, <main>, <footer> se utilizan para definir diferentes secciones del contenido con significado semántico.

¿Cuál es la diferencia entre una etiqueta <ol> y una etiqueta <ul> en HTML?

<ol> crea una lista ordenada con números o letras, mientras que <ul> crea una lista desordenada con viñetas.

¿Con qué etiqueta de HTML puedo poner un texto en cursiva?

Con <em> para poner en cursiva con semántica y la etiqueta <i> solo para estilizar sin significado semántico.

¿Cómo crear un enlace en HTML?

Con la etiqueta <a> y utilizando el atributo href para la URL del enlace.

¿Qué diferencia hay entre un <tr> y un <td> en HTML?

<tr> define una fila en una tabla, mientras que <td> define una celda dentro de esa fila.

¿Cómo abrir un enlace en una pestaña nueva en HTML?

En la etiqueta <a> agregándole el atributo target='_blank' para que el enlace se abra en una nueva pestaña o ventana.
